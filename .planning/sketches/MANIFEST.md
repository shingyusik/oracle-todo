# Sketch Manifest

## Design Direction

Keep the existing warm, quiet Raven Dashboard while fitting Today's work, Completion history, and a combined Status visualization on one desktop row. Project status prioritizes finding abandoned work through the existing Risk and Attention classification.

## Reference Points

- Current Raven Dashboard screenshot and data density
- Existing Project `Risk` and `Attention` semantics
