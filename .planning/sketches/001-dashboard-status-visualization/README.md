# Sketch 001: Dashboard Status Visualization

## Design Question

Which compact visualization reveals abandoned Projects fastest while preserving access to Area status?

## How to View

Open `.planning/sketches/001-dashboard-status-visualization/index.html`.

## Variants

- **A: Risk Treemap** — work-sized tiles colored by existing Project attention.
- **B: Risk Lanes** — Project bubbles grouped into Risk, Attention, and Normal lanes.
- **C: Mini Donuts** — status rings in a compact Project grid with attention borders.

## Winner

**C: Mini Donuts** keeps status composition readable while the Risk and Attention borders make abandoned Projects immediately scannable.

## What to Look For

Compare how quickly each variant exposes an abandoned Project, how much exact status context remains visible, and whether the combined Status card still fits beside the two existing charts.
