# Sketch 002: Dashboard Ledger Highlights

## Design Question

Should the Ledger highlights row below ToDo analytics read as three separate cards or one shared analysis surface with internal dividers?

## How to View

Open `.planning/sketches/002-dashboard-ledger-highlights/index.html`.

## Variants

- **A: Three cards** — Cash flow, spending categories, and the trend each have their own border and heading.
- **B: Shared surface** — One Ledger container owns the controls and divides the three charts internally.

## Winner

**B: Shared surface** keeps the period and currency controls visibly shared while the internal `1:1:2` divisions preserve each chart's role without making the Dashboard look like three unrelated reports.

## What to Look For

Compare whether the controls feel clearly shared, whether the `1:1:2` proportion is readable, and whether the row feels like a Dashboard highlight instead of a duplicate Report page.

The period, currency, and trend tabs are interactive. `Previous month` demonstrates the agreed overspending state, and `USD` demonstrates the no-activity state.
